# Maheen Mohamed Ismayeel — Portfolio

Personal portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and Lenis.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Editing content

All text, links, skills and projects live in [`src/data.ts`](src/data.ts) — update that file and the sections update with it.
Sections are in `src/components/`, shared animation helpers in `src/components/ui/`.
